# 为什么要重构底座

目前的底座源码过于臃肿，许多功能堆叠在一起，不方便后续开发和维护，所以需要对底座进行重构。

主要是将底座进行模块化，将功能解耦，方便后续开发和维护。

# LLM
大模型这一块之前已经进行了模块操作， 这一步是换种实现方式，用OpenAI的官方库来进行大模型的请求
后续也方便做兼容处理

# Tools
将工具功能从Agent Loop抽离出来，抽象为一个新的Tools对象， 将工具相关的功能作为对象的方法， 比如工具的注册，工具的调用，工具输出的统一处理等

Tool和Tools是两个不同的概念，Tool是单个特定的工具，包含方法和schema定义，而Tools不仅仅是Tool的集合，也是使用Tool的接口。
## ToolError

```python
class ToolError:
    """工具失败时返回给调用方和模型的稳定错误信息。"""
    code: str  # 错误码
    message: str # 错误消息
    retryable: bool = False  # 是否可重试
    details: dict[str, Any] | None = None  # 错误详情
```

# Context 
目前的上下文设计过于简单了， 一个message存储上下文信息， 但是没有上下文的管理功能
抽象出一个Context对象，是为了更好的管理上下文， 同时更好的支持上下文功能的扩展和维护，比如上下文压缩，上下文存储，上下文检索等

# Runtime
这是运行时， 将运行相关的功能，也就是Agent Loop相关的功能抽象到了Runtime中， 这里主要用于保证运行中没有问题
