Agent 是什么？Agent 又被称之为智能体，通俗的说就是一个可以理解你的需求并帮你干活的一个 AI。

一个基本的 Agent 结构包含大语言模型、上下文、Agent Loop 以及 Tools。

以一个抽象的方式来理解：
    将Agent看作是一个人的基本组成，大语言模型，就是大脑，负责思考和决策；
    上下文就是记忆
    Agent Loop 则是心脏，推动血液的循环，输送养分，维持系统的基本运转；
    Tools 像是功能型器官以及肢体，有了它们，Agent 才能真正的做事。


# 大模型是什么

在 Agent 中，大模型通常指的是大语言模型，英文是 Large Language Model，简称 LLM。
大语言模型作为Agent的大脑，它是非常重要的一个部件，而大模型的强弱则对应这个Agent的智商的强度，对于简单的任务来说，大模型的强弱并没有太大的差距。
就像你问小学生 1+1 等于几，和问大学生 1+1 等于几，其实没有什么差别。 
但是在复杂的问题推理上，他们的差距是非常大的。还是刚才的例子，你问小学生线性代数，他可能认识这四个字，但是连起来他们会一脸懵逼。

如果一个 Agent 中缺少了大模型的存在，那么它就只是一个无用的躯壳，存在与否意义就不大了（路易十六）。

# 上下文

对于大模型而言，它是没有记忆的，而上下文就相当于 Agent 的记忆，接下来要做什么要根据之前的记忆来推断，我们每一次向大模型发送消息，都要将之前的消息记录全部发送给大模型，这就是上下文。

如果没有上下文，那么每一次和大模型的对话都是全新的.
就好比你提了一个问题: 大爷，你认识马冬梅吗？
大爷说:认识啊
她住哪的。
谁住哪？
马冬梅。
马冬梅怎么了？
她住哪儿？
谁啊？
。。。。。。【无语】
谢谢啊
为啥谢我？
再见。

可能你会有一个问题：他既然记不住，为什么能知道马冬梅呢？有没有一种可能是说这个大爷他本身的记忆里是有马冬梅的，他只是记不住你们的对话。


# agent loop 是什么

Agent Loop是由大模型主导的一个自主循环体，负责推动Agent的运转。

常规的AI会话基本上是一问一答，或许他能为你解决一些问题，但是他不能真正的帮你工作。

在 Agent Loop 中，用户向大模型发送一个指令，大模型根据情况判断是否需要调用外部工具，如果不需要调用外部工具，那么可以直接在这条回复过后结束此次循环。
如果需要调用外部工具来获取更多信息或执行操作，LLM会发回调用请求，然后 Agent Loop 根据该请求调用具体的 Tools（工具），调用完成后，再将调用结果再发给大模型，大模型根据调用的结果来判定下一步是继续调用工具还是结束此次循环。 


如果没有这个agent loop呢，会是什么样子？
每一次对话，大模型都会口头回应一次，事事有回音，事事不落实。 就像老板给你画的大饼...

就像大敌当前，韩立脑子里想： 此地危险，为了安全，需将众人护至身前。 
但是想归想，身体丝毫未动, 身体和脑子各玩各的。

# Tools
 Tools翻译过来就是工具，大模型只有推理和决策的功能，很多环境感知，操作等功能，单纯靠大模型是没办法单独办到的，举个例： 
   比如千手柱间，双手合十，喊啥来啥，分别是大脑（LLM）发送指令，双手和嘴巴（tools）执行指令， 但如果秽土转生出现了问题， 忘了把柱间的四肢和声带带来...
大模型发送的工具调用请求包含工具名、参数等信息，工具是本地执行，和大模型无关，大模型只接收结果。 

如果没有 Tools 会怎样？
    就好比汤师爷说：我屁股疼
    张麻子：屁股在树上呢。 
    
没有tools， LLM甚至感知不到有屁股，当然也不可能感觉到屁股疼。
